Você está no passo **/clarify** do processo Spec-Driven Development.

Faça:
1. Leia a `spec.md` da feature atual.
2. Liste todos os marcadores `[NEEDS CLARIFICATION: ...]`.
3. Para cada um, faça ao usuário uma pergunta objetiva (com opções quando
   possível). Não invente respostas.
4. Atualize a `spec.md` substituindo cada marcador pela decisão tomada,
   registrando-a na seção "Pontos em Aberto" como resolvida.
